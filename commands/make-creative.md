---

Design a creative: **$ARGUMENTS**

Route by asset type and follow the Design Pro loop:

1. **Orient & lock the canvas** — read `knowledge/INDEX.md`, then **`knowledge/08-visual-composition/format-specs.md`** to set exact dimensions, aspect, DPI, bleed, and color space (sRGB screen / **CMYK + 3 mm bleed @300 DPI** for print). Read `composition.md`.
2. **Load the matching playbook:**
   - Poster / flyer / brochure / card / banner / event signage → `knowledge/11-print-and-events/print-posters.md`
   - Social post / story / thumbnail / ad → `knowledge/10-social-creatives/social-posts.md`
   - Email / newsletter → `knowledge/12-email-design/email.md`
   - Plus `knowledge/08-visual-composition/imagery-and-icons.md` and `brand-systems.md`.
3. **Design** — one focal point and one clear message + one CTA; hierarchy for the real viewing distance (poster reads across a room; thumbnail reads at 120px; email scans on mobile); apply the brand system (derive one from a given color/font if none exists); restraint pass (one accent, consistent grid, generous margins, no clip-art/gradient-soup).
4. **Produce** — per `knowledge/13-production/production-and-tools.md`: HTML→PNG for social, HTML→PDF (with `@page` bleed) for print, MJML/table-HTML (CSS inlined) for email. Verify fonts, dimensions, color space, and resolution on the rendered file.
5. **Self-review** against `knowledge/05-quality/review-checklist.md` and the production checklist (and, for print, the screen-to-print gotchas table).

Apply sensible defaults for anything unspecified and state assumptions. Deliver the producible source/output plus the chosen specs, brand tokens, and production method.
