# Creative Brief Template (fixed-canvas: deck / social / print / email)

> Copy, fill in, hand to the agent (or a `/make-deck` · `/make-carousel` · `/make-creative` command). Blanks get sensible defaults from the knowledge base — and the agent states the assumptions it made. For anything sized, the agent locks dimensions from `knowledge/08-visual-composition/format-specs.md` first.

## 1. What & where
- **Asset type:** deck / carousel / social post / story / ad / poster / flyer / brochure / business card / banner / email / infographic / one-pager
- **Channel & placement:** (e.g. Instagram feed, LinkedIn, printed A3 at an event, sent via Mailchimp)
- **Print or screen?** → if print: trim size + finish; if screen: platform(s)
- **Quantity / set:** single asset, or a series that must look like one family?

## 2. Goal
- **One core message:** the single thing it must communicate.
- **One primary action / CTA:** what should the viewer do? (scan QR, swipe, register, buy, reply)
- **Success looks like:** (signups, attendance, saves, replies)

## 3. Audience & tone
- **Who sees it?** and in what context (scrolling on a phone, walking past a poster, opening email on mobile)
- **Mood / tone:** e.g. premium, energetic, trustworthy, playful, editorial, technical

## 4. Brand & assets
- **Brand color(s) / kit:** hex/tokens, or "derive a kit from this color/logo"
- **Logo:** provided? on-light/on-dark versions?
- **Fonts:** brand fonts, or "pick a pairing"
- **Imagery:** photos/illustration/icons provided, AI-generate, or none (type-led)?
- **References to match:** links or brands whose quality bar to hit
- **Must-include:** legal text, disclaimers, sponsor logos, dates, URLs, QR

## 5. Content
- **Headline / hook:** (or "write it")
- **Body copy / slides / sections:** the actual text, or key points to cover
- **For decks:** type (pitch/sales/internal), # slides, speaker-support vs leave-behind
- **For carousels:** topic + pattern (listicle / how-to / myth-vs-fact / story), # slides
- **For email:** sections, primary CTA, preview text

## 6. Output & production
- **Deliver as:** rendered files (PNG/PDF/PPTX/MP4) and/or editable source (HTML/PPTX/Express/Canva)?
- **Will you keep editing it?** (if yes → hand off editable source)
- **Deadline / size limits:** (file weight for email/web, print spec from the printer)

## 7. Out of scope / notes
- Anything explicitly NOT to do; open questions.
